# 武器统一橙色品质

客户端 `Tip.GetGradeColor(5)` 对应 `ARGB(255, 255, 128, 0)`，品质背景为 `skin_common_weapon_bg05.tga`。所有类型 2、子类型 1–16 的武器统一使用 `grade=5`，共 968 件，包括 478 件大冲锋移植武器。

`shop_config.json` 同步修改商品品质与提示信息的品质字段。`WeaponQuality.Resolve` 为商店物品、背包物品和缺少背包引用的旧快捷栏提供统一规则，旧存档无需删除或重新购买；保存时会写出橙色品质。徽章、背部装备、造型卡和其他物品保留原品质，武器价格、属性、PID 及强化进度保持原数据。移植商品注册脚本也明确生成橙色武器。
